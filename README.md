## 👑 Key Features & Highlights

### 1. Interactive "Choose Your House" Engine
Visitors can pledge allegiance to one of four Great Houses directly on the landing page or navbar:
- **House Stark (The Direwolf)**: *Discipline & Resilience* — Ice Blue theme `#9BC7DF` with falling snowflakes and frost wind.
- **House Targaryen (The Dragon)**: *Ambition & Power* — Blood Red theme `#E63946` with floating fire embers and sparks.
- **House Lannister (The Lion)**: *Strategy & Intelligence* — Antique Royal Gold theme `#C5A15B` with shimmering golden motes.
- **The Night's Watch (Cyber Defense)**: *Shield of the Realm* — Obsidian & Cyber Cyan `#00F0FF` with digital binary snow and circuit traces.

*Selecting a house dynamically recalculates CSS design tokens, particle physics, and audio ambiance across the entire website in real time.*

### 2. 100% Original Royalty-Free Procedural Audio Engine
- **Zero Copyright Risk**: Built directly with the native Web Audio API using procedural sound synthesis.
- **Features**: Deep resonant cello & contrabass drone, cinematic war drums (taiko heartbeats), ethereal choral pads, and medieval court plucked arpeggios.
- **Floating Music Player**: Integrated play/pause, volume slider, mute/unmute, track information (`Crown & Cipher`), and a real-time animated 16-bar frequency visualizer driven by an `AnalyserNode`.
- **Browser Autoplay Compliant**: Safely initiates only after visitor interaction.

### 3. Canvas Particle Physics Engine
- High-performance, GPU-accelerated HTML5 `<canvas>` rendering.
- Dynamically shifts between **falling snow**, **rising fire embers**, and **royal golden dust** based on the chosen House.
- Subtle cursor interaction: moving your cursor gently displaces atmospheric particles.
- Fully respects `prefers-reduced-motion` for accessibility.

### 4. Medieval Parchment <-> Cyber Terminal Decryptor
- The **About Section** features an ancient parchment manuscript sealed by royal archives.
- Includes an interactive **[CYBER DECRYPTOR VIEW]** toggle that transforms the medieval parchment into a live cyber terminal terminal with commands like `whoami`, `cat /var/log/realm/mission.txt`, and `status --determination`.

### 5. Authentic Beginner-Level Arsenal (No Fake 95% Skills)
- Tailored for a real first-year student in their first semester.
- Categorized into:
  - **Programming (House of the Forge)**: C, Python, HTML, CSS — labeled as **Learning**.
  - **Cybersecurity (House of the Shield)**: Cyber Fundamentals, Networking, Linux, Ethical Hacking Concepts, InfoSec Basics — labeled as **Exploring**.
  - **Tools & Technology (House of the Apparatus)**: Git/GitHub, VS Code, Linux Terminal — labeled as **Learning** / **Familiar**.
- Features glowing golden learning progress gauges with rune tips.

### 6. Battles (Projects) & Chronicles (Journey Timeline)
- **Projects Showcase**: Interactive cards featuring 3D mouse tilt, specular glare, status badges (*In Progress*, *Learning / Planned*), technology tags, and repository inspection modals.
- **The Chronicles of My Journey**: A vertical timeline styled like a royal scroll with a golden spine and glowing milestone nodes depicting Chapters I through V.

## 🚀 How to Run the Website

### Option 1: Instant Standalone Launch (Zero Dependencies)
You don't even need Node.js or npm installed to experience the website!
1. Navigate to:
   ```
   C:\Users\adity\.gemini\antigravity\scratch\realm-of-cyber
   ```
2. Double-click `index.html` to open it in your browser (Chrome, Edge, Brave, Firefox, Safari).
3. Everything (styles, icons, particles, procedural audio, 3D tilt, modals) runs completely offline!

### Option 2: Run with the Lightweight Local Server
To run a local HTTP server:
```bash
node server.js
```
Then open:
```
http://localhost:3000
```

### Option 3: Modern React + Vite Development
The repository also includes the complete React 18 + Vite + Tailwind CSS source code:
```bash
npm install
npm run dev
```

## 🌐 Deploying to the Web

You can deploy this website for free in under 2 minutes:

### Deploying to GitHub Pages:
1. Push this folder to a GitHub repository named `username.github.io` (or `realm-of-cyber`).
2. Go to **Settings > Pages** in your repository.
3. Select the `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo>/`!

### Deploying to Vercel or Netlify:
- Drag and drop this folder directly into the **Netlify Drop** dashboard, or connect your GitHub repository to **Vercel** for automatic continuous deployment.
